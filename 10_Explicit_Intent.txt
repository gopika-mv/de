EXPLICIT INTENT

Purpose: Navigates from one Activity to another Activity and can
transfer data.

XML – activity_main.xml

Java – MainActivity.java EditText etName; Button btnNext;

etName = findViewById(R.id.etName); btnNext =
findViewById(R.id.btnNext);

btnNext.setOnClickListener(v -> { String name =
etName.getText().toString();

    Intent intent = new Intent(MainActivity.this, SecondActivity.class);
    intent.putExtra("username", name);
    startActivity(intent);

});

Java – SecondActivity.java TextView tvName;
setContentView(R.layout.activity_second); tvName =
findViewById(R.id.tvName);

String name = getIntent().getStringExtra(“username”);
tvName.setText(name);

Create SecondActivity.java and activity_second.xml. Ensure the Activity
is registered in AndroidManifest.xml if Android Studio has not done it
automatically.

Important methods: - new Intent() – Create Intent. - putExtra() – Send
data. - getStringExtra() – Receive String data. - startActivity() – Open
another Activity.
